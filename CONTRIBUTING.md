# Contributing to Print 3D Studio Landing Page

Thank you for your interest in contributing! 🎉

## How to Contribute

### 1. Fork & Clone
```bash
# Fork repository trên GitHub
# Clone về máy
git clone https://github.com/YOUR-USERNAME/print-3d-studio-landing.git
cd print-3d-studio-landing
```

### 2. Create Branch
```bash
git checkout -b feature/your-feature-name
```

### 3. Make Changes
- Follow existing code style
- Test thoroughly
- Write clear commit messages

### 4. Commit
```bash
git add .
git commit -m "✨ Add your feature description"
```

### 5. Push & Pull Request
```bash
git push origin feature/your-feature-name
```
Then create Pull Request on GitHub.

## Code Style

### HTML
- Use semantic HTML5 elements
- Include ARIA labels for accessibility
- Use kebab-case for IDs and classes

### CSS
- Follow BEM naming convention
- Use CSS custom properties for theming
- Keep specificity low
- Write mobile-first media queries

### JavaScript
- Use ES6+ features
- camelCase for variables and functions
- PascalCase for classes
- Add JSDoc comments for functions

## Commit Message Format

Use emoji prefixes:
- ✨ `:sparkles:` New feature
- 🐛 `:bug:` Bug fix
- 📝 `:memo:` Documentation
- 💄 `:lipstick:` UI/Style
- ⚡ `:zap:` Performance
- ♿ `:wheelchair:` Accessibility
- 🔧 `:wrench:` Configuration
- 🚀 `:rocket:` Deployment

Example:
```
✨ Add newsletter subscription form
🐛 Fix mobile menu overlay z-index
💄 Update button hover animations
```
