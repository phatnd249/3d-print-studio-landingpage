# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-01-28

### Added
- 🎨 Modern glassmorphism navigation with backdrop blur effects
- 📱 Fully responsive design for mobile, tablet, and desktop
- ⚡ Hero section with gradient background and 3D printer illustration
- 🛠️ Services section showcasing 6 main services with icon cards
- 💡 "Why Choose Us" section with 6 key benefits
- 🧪 Materials section featuring 5 types of 3D printing materials (PLA, PETG, PETG-CF, ABS, TPU)
- 💰 Pricing reference section with quote request CTA
- 🖼️ Gallery section displaying 6 sample projects
- 📰 News/Blog section with empty state (ready for API integration)
- 📧 Contact footer with social media links
- 🎭 Modal form for quote requests with material selection
- ✨ Smooth animations and hover effects throughout
- 🔤 Inter font for improved readability
- 🎯 SEO optimization with meta tags and semantic HTML

### Changed
- 🔤 Typography updated to Inter font family for better readability
- 📏 Increased logo sizes: Header (72px) and Footer (120px)
- 📝 Improved line-height (1.7) and font-weight (500) for body text
- 🎨 Enhanced color palette with gradient backgrounds
- 💫 Refined hover effects and transitions

### Technical
- 📦 Modular CSS architecture with separate section files
- 🎯 CSS custom properties for easy theming
- 📱 Mobile-first responsive design approach
- ♿ Accessibility improvements (ARIA labels, semantic HTML)
- ⚡ Performance optimizations (lazy loading, inline SVG icons)
